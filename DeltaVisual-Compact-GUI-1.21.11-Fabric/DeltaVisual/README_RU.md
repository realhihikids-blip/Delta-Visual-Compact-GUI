# Delta Visual — Minecraft 1.21.11 Fabric

Это release-candidate исходный проект визуального клиентского мода с собственным тёмно-фиолетовым ClickGUI. Это **не готовый и не проверенный релиз**: архив содержит основу проекта и несколько реально подключённых функций; перед публикацией необходимо собрать и протестировать проект в среде с JDK 21 и доступом к Maven.

## Уже подключено в исходниках
- Fabric client entrypoint и открытие GUI клавишей Right Shift.
- ClickGUI переработан под компактную пятиколоночную компоновку Combat / Movement / Render / Player / Misc по визуальному ориентиру пользователя.
- Переключатели HUD, Reach Display для видимого игрока и Aura Cosmetics.
- Косметическая панель настроек: пресеты цвета, стиль/радиус ауры.
- HUD-плашка и отображение расстояния до видимого игрока под прицелом.
- Быстрые клавиши для выбора эндер-жемчуга в хотбаре и уведомление при отсутствии.
- Безопасные подсказки для Totem/Elytra helper: автоматические инвентарные клики и скрытые пакетные манипуляции не выполняются.
- JSON-конфигурация в `config/delta-visual.json`, загрузка/сохранение, проверка и сброс повреждённого файла.
- Назначение клавиш в интерфейсе (клавиатура и базовые кнопки мыши).

## Что ещё требуется реализовать/проверить
- Полноценный рендерер Aura Cosmetics (сейчас есть только настройки-переключатели; частицы ещё не подключены).
- Полноценный HUD Editor с перетаскиванием и сохранением координат.
- Полный набор профилей, HEX/RGB-поле и выбор шрифтов, реально применяемых ко всему интерфейсу.
- Надёжный event-driven менеджер биндов с поддержкой боковых кнопок мыши, конфликтами и блокировкой исходного клика.
- Player-name/armor HUD и визуальные эффекты мира.
- Реальная компиляция/проверка на Minecraft 1.21.11; в этом окружении сборка не запускалась.

## Сборка
Требуется JDK 21. Открой папку проекта в IntelliJ IDEA с Gradle или запусти:
- Windows: `gradle build` (если Gradle установлен)
- Linux/macOS: `gradle build`

После успешной сборки JAR будет в `build/libs/`. Для полноценной установки нужен Fabric Loader для Minecraft 1.21.11 и Fabric API той же версии.

## Принципы
Только Fabric, без Forge/NeoForge. Нет KillAura, Reach-изменения, X-Ray, ESP сквозь стены или автоматического наведения. Reach Display — только информационный текст до видимой цели, не меняющий механику игры.


## Стиль GUI
GUI использует компактный встроенный Minecraft sans-serif шрифт, тёмные полупрозрачные колонки, фиолетовый верхний акцент, плотные строки модулей и отдельную область настроек. Внешний TTF не встроен: используемый шрифт зависит от Minecraft resource/font settings.
